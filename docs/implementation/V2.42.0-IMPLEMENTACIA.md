# Flow v2.42.0 – Implementácia

## Cieľ

Stabilizovať výber výdavkového modelu podľa kategórie a odstrániť overfitting mesačného meta-selectora z v2.41.0.

## Zmeny

1. Category champion sa vyberá na úrovni celej kategórie.
2. Historický scenario archive poskytuje počiatočný prior.
3. Pridaný kandidát `multi-year-trend` podľa v2.38.2.
4. Challenger potrebuje materiálne zlepšenie, inak zostáva prior.
5. Income Engine nebol menený.
6. Backend sa nemení.

## Očakávané správanie

- Strava a Osobná starostlivosť by mali preferovať recent robust.
- Poistenie má prior last-year.
- Dane majú prior seasonal-index.
- Domácnosť/Darčeky/Deti/Domáce zvieratá používajú multi-year trend ako počiatočný prior.
- Dovolenky a Doprava zostávajú konzervatívne na adaptívnom modeli, kým challenger nepreukáže jasné zlepšenie.
