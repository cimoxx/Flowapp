# Flow v2.49.11 – príjmový progress v aktuálnom mesiaci

Základom ostáva v2.49.10, kde je celý `planning.js` obnovený zo stabilnej v2.49.2.

Do `renderCurrentMonthProgress(month)` bola vrátená iba predtým funkčná UI časť z v2.49.3:
- `actualIncome` = reálne prijaté príjmy z transakcií
- `plannedIncome` = očakávaný príjem pre celý aktuálny mesiac
- progress = `actualIncome / plannedIncome`
- `incomeRemaining` = max(0, plannedIncome - actualIncome)

Nebola zmenená funkcia `getAnnualPlan(year)` ani forecast/income výpočtový engine.

Bez zmeny:
- sync
- HIST tombstones
- Google Apps Script
- Budget
- Forecast model
