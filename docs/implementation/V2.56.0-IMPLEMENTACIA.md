# Flow v2.56.0 – Kompaktnejší formulár Nová transakcia

Apps Script sa nemení. Výpočty sa nemenia. Mení sa iba vzhľad formulára (`index.html`, `assets/css/styles.css`).

## Čo sa zmenilo
- Odstránená karta „Predvolené hodnoty“ (iba opisovala, čo si appka pamätá) a jej štýly.
- Podnadpis hlavičky („Rýchle pridanie novej položky…“, pri úprave „Zmeň údaje…“) je skrytý (`#modal-subtitle { display: none }`), v kóde ostáva.
- Medzery vo formulári `space-y-5` → `space-y-3`, pole sumy `text-5xl py-2` → `text-4xl py-1`, dlaždice kategórií `min-height` 64 → 56 px.
- Poznámka a dátum sú vedľa seba (`grid-cols-[1.35fr_1fr]`, polia majú `min-w-0`), predtým pod sebou na telefóne.
- Pravidelná platba je jeden riadok s prepínačom. Vysvetľujúci text sa presunul do `#recurring-options`, ktoré sa rozbalia po zapnutí.
  Funkcie (`toggleRecurringOptions`, `f-recurring`, `f-frequency`) sa nezmenili.

## Zmerané (Chromium, skutočné rozloženie, formulár Nová transakcia)
| Telefón | Výška obsahu pred → po | Poznámka a dátum bez posúvania pred → po |
|---|---|---|
| 390×844 | 1 159 → 798 px | nie → áno |
| 412×915 | 1 143 → 798 px | iba poznámka → áno |
| 360×740 | 1 159 → 798 px | nie → nie (sheet je najviac 92 % výšky, posúva sa menej) |

Pravidelná platba v zbalenom stave: 98 → 42 px. Bez pretekania do strán na všetkých troch veľkostiach.

## Čo som nemenil
Mriežka kategórií (4 stĺpce), podkategórie, „Často používané“, spôsob ukladania a úpravy transakcie.
Väčšia zmena (kategórie v jednom riadku, Uložiť dole) je samostatný nápad.
