# Flow v2.44.6 – Presnosť starších mesiacov

- Staršie uzavreté mesiace sa spätne doplnia férovým historickým výpočtom.
- Používajú sa iba údaje, ktoré boli dostupné pred daným mesiacom.
- Nové mesiace používajú reálny plán uložený počas mesiaca.
- UI používa zrozumiteľné názvy: Rozpočet, Odhad, Skutočné výdavky.
- Výpočtové algoritmy Budgetu a Forecastu sa nemenia.
