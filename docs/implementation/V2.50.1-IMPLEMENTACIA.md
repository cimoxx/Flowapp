# Flow v2.50.1 – Príjmy aktuálneho mesiaca

V Ročnom pláne pri aktuálnom mesiaci pribudla samostatná karta **Príjmy mesiaca**.

Zobrazuje:
- príjmy prijaté doteraz (`actualIncome`),
- očakávaný príjem za celý mesiac (`plannedIncome`),
- percento prijatých príjmov,
- progress bar.

Výpočet príjmov sa nemení. UI iba zobrazuje existujúce hodnoty Income Engine zrozumiteľnejšie.

Výdavková časť bola iba textovo zjednodušená. Budget, Forecast, Income Engine, synchronizácia, Google login a GAS zostávajú funkčne nezmenené.
