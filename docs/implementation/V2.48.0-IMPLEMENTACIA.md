# Flow v2.48.0 – UX konsolidácia

Prejdené hlavné obrazovky aplikácie so zameraním na informačnú hierarchiu a duplicity.

- Prehľad: odstránené opakované zobrazenie rezervy/Safe to Spend.
- Rozpočet: hlavný plán zostáva otvorený, sekundárny odhad a upozornenia sú zbaliteľné.
- Terminológia: používateľsky Rozpočet a Odhad namiesto Budget/Forecast.
- Analytika a Tempo míňania: zjednotené názvy filtrov.
- Výpočtové algoritmy a dátová vrstva sa nemenia.
