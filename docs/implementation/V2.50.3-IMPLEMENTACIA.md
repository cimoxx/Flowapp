# Flow v2.50.3 – Bezpečnosť a stabilita

Vychádza z v2.50.1 (kompaktná hlavička). Finančné výpočty (Budget, Forecast, Income Engine) sa nemenia.

## Zmeny vo frontende

- `utils.js`: nové pomocné funkcie `escHtml()` (text do HTML) a `jsArg()` (hodnota do inline `onclick`).
- Escapované zobrazenie poznámky, kategórie, podkategórie a ID transakcie v zozname transakcií, súhrnných kartách, výbere kategórie a podkategórie, nastaveniach kategórií, analytike, burn rate, budgete a v toast notifikáciách.
  - Predtým sa dal cez Google Sheets (alebo cez API s verejným tokenom) uložiť text, ktorý sa v aplikácii spustil ako kód.
  - Apostrof alebo úvodzovky v názve podkategórie či v ID rozbili `onclick`.
- `index.html` + `sw.js`: Lucide `1.58.0` a Chart.js `4.5.1` s pevnou verziou namiesto `@latest`. CDN súbory sa cachujú jednotlivo, takže výpadok CDN nezhodí inštaláciu service workera.
- `sync.js`: porovnanie s cloudom cez `Set` namiesto prehľadávania celého poľa pre každý lokálny záznam.

## Google Apps Script v2.50.3 (voliteľné)

`google-apps-script/Flowapp-Google-Apps-Script-v2.50.3.gs` = v2.49.21 + rýchlejší `batchSync`:
- stĺpec ID sa pri dávke načíta iba raz (predtým raz pre každú položku),
- hlavičky Sheet1 sa kontrolujú raz za dávku.

API ani formát dát sa nemenia. Frontend v2.50.3 funguje aj so starým backendom v2.49.21.

### Nasadenie GAS
1. Otvor projekt Apps Script pripojený k tabuľke Flow.
2. Nahraď obsah skriptu súborom v2.50.3.
3. Nasadiť → Spravovať nasadenia → upraviť existujúce nasadenie → Verzia: **Nová verzia** → Nasadiť.
   (Úprava existujúceho nasadenia zachová URL, takže `config.js` netreba meniť.)
