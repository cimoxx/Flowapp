# Flow v2.38.7 – Backtest Repair

## Prečo vznikla táto verzia
Vo v2.38.6 sa walk-forward backtest vytvoril vo frontende, ale Google Apps Script neukladal pole `backtest`. Po opätovnom načítaní preto aplikácia nevedela rozpoznať archivované riadky ako historický backtest a metriky zostali na 0. Zároveň už uložené neúplné riadky blokovali nové vytvorenie toho istého modelu.

## Oprava
- `FlowForecastArchive` ukladá aj `backtest`, `dataYears`, `seasonalYears`, `actualVariableAmount` a `recurringBaseline`.
- Existujúce neúplné riadky sa nepovažujú za platný backtest a neblokujú regenerovanie.
- Ukladanie archívu prebieha po dávkach 100 riadkov.
- Tlačidlo zobrazuje priebeh `Pripravujem…` / `Ukladám x/y`.
- Chyby sa zobrazia toastom a zapíšu do konzoly.

## Nasadenie
1. Nahraď frontend celým obsahom balíka v2.38.7.
2. V Google Apps Script nahraď aktuálny kód súborom `Flowapp-Google-Apps-Script-v2.38.7.gs`.
3. Deploy → Manage deployments → Edit → New version → Deploy.
4. URL Web App ponechaj rovnakú.
5. Otvor Ročný plán a spusti `Vyhodnotiť históriu`.

Existujúce údaje v Google Sheets sa nemažú.
