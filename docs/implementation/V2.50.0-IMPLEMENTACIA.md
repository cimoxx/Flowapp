# Flow v2.50.0 – Súkromné Google prihlásenie

## Čo je chránené
- Flow pred prihlásením nevykreslí finančné dáta.
- Google ID token sa používa iba pri prihlásení.
- Backend ho overí u Google a skontroluje Client ID, issuer, expiráciu a overený email.
- Povolený účet sa prepojí cez stabilné Google `sub`.
- Backend následne vytvorí vlastnú náhodnú session na 7 dní.
- Pri každom GET/POST sa overuje session. Starý zdieľaný API token už nie je autentifikácia.
- Po explicitnom odhlásení sa citlivá lokálna cache vyčistí.

## Nastavenie – spravíš raz

### 1. Google Cloud
V Google Cloud Console vytvor `OAuth 2.0 Client ID` typu **Web application**.
Do **Authorized JavaScript origins** pridaj:
`https://cimoxx.github.io`

Skopíruj Client ID v tvare:
`123456789-....apps.googleusercontent.com`

### 2. Google Apps Script
Otvor:
`google-apps-script/Flowapp-Google-Apps-Script-v2.50.0.gs`

Zmeň:
`FLOW_GOOGLE_CLIENT_ID`

a do `FLOW_BOOTSTRAP_EMAILS` vlož Google účty, ktoré smú používať Flow.

Príklad:
```
const FLOW_BOOTSTRAP_EMAILS = [
  'prvy.ucet@gmail.com',
  'druhy.ucet@gmail.com'
];
```

Potom v Apps Script editore spusti **setupFlowAuth** raz ručne.
Vzniknú hárky:
- `FlowUsers`
- `FlowSessions`

### 3. Deploy
Aktualizuj Web App deployment:
- Execute as: **Me**
- Who has access: **Anyone**

`Anyone` je potrebné preto, aby sa neprihlásený browser vôbec dostal k login endpointu. Finančné endpointy sú chránené serverovou session a bez prihlásenia dáta nevydajú.

## Správa používateľov
V hárku `FlowUsers`:
- `Email` = povolený účet,
- `GoogleSub` sa doplní pri prvom úspešnom prihlásení,
- `Role` = owner/member,
- `Active` = TRUE/FALSE.

Ak chceš niekomu prístup zrušiť, nastav `Active` na FALSE a v `FlowSessions` môžeš jeho aktívne sessions nastaviť na FALSE.

## Poznámka
Google Identity Services vyžaduje bezpečný browser. Prihlásenie používaj cez normálny Chrome/PWA, nie vložený webview.
