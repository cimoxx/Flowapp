# Flow v2.42.2 – Dark Mode Contrast Fix

Táto verzia opravuje čitateľnosť Budgetu a Ročného plánu v dark mode.

## Hlavná príčina
Globálny dark režim prepínal text na svetlý, ale niektoré dynamicky renderované karty si ponechali svetlé pozadie. Výsledkom bol biely text na takmer bielom pozadí.

## Oprava
- povrchy používajú `var(--bg-card)`, `var(--bg-soft)` a `var(--border)`,
- text používa `var(--text-main)` / `var(--text-dim)`,
- kritické dynamické karty majú explicitné `!important` override,
- CSS je načítavané s `?v=2.42.2`, aby PWA nepoužívala starú cached verziu.

## Backend
Google Apps Script sa nemení.

## Model
Forecast a Income Engine sa nemenia.
