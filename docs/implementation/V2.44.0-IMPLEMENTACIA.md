# Flow v2.44.0 — Financial Cockpit

## Cieľ
Pridať rýchly mesačný prehľad bez zásahu do existujúcej finančnej logiky.

## Implementácia
- nový `assets/js/cockpit.js` je iba prezentačná vrstva,
- číta existujúci `getBudgetDataset()` a `buildBudgetInsights()`,
- nemení `budget.js`, `planning.js`, `sync.js`, `transactions.js`, `categories.js` ani GAS,
- pri multi-month výbere nevytvára zavádzajúci agregovaný mesačný forecast,
- UI je responzívne a má dark-mode variant.

## Regresná ochrana
`assets/js/budget.js`, `assets/js/planning.js`, `assets/js/sync.js`, `assets/js/transactions.js`, `assets/js/categories.js` a GAS musia zostať byte-identické s v2.43.5.
