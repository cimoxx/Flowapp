# Flow v2.38.3

- Multi-year forecast uses all available historical years with recency weighting, seasonality and restrained trend.
- Walk-forward historical evaluation uses only data available before the target month; current recurring plans are not used as historical inputs.
- Forecast index avoids repeated full-database scans.
- Budget category monthly aggregation uses the forecast index when available.
- Service worker immediately activates the new version and removes obsolete caches.
- Google Apps Script supports planning/archive actions and batch-writes forecast archive rows.
- Recurring transaction generation remains capped at a rolling 12-month horizon.

## v2.38.3 – rýchly filter transakcií
- Rýchly filter kategórií a podkategórií je zobrazený iba na obrazovke Transakcie.
- Kategórie sa zobrazujú iba v prvom stave.
- Po výbere kategórie sa zobrazia iba jej podkategórie.
- Podkategória je vždy filtrovaná v rámci vybranej kategórie.
- Opätovným kliknutím na aktívnu kategóriu sa filter zruší.
- Opätovným kliknutím na aktívnu podkategóriu sa zruší iba podkategóriový filter.
- Opravené bolo duplicitné zobrazovanie kategórií/podkategórií v rýchlom filtri.
