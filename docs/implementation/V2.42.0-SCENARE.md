# Flow v2.42.0 – Scenario evidence

Zdroj: `forecast scenare.xlsx` (doterajší walk-forward archív).

## Záver

Najlepší model nie je rovnaký pre všetky kategórie. Mesačný selector z v2.41.0 bol preto nahradený stabilnejším category-champion prístupom.

## Silné empirické signály

- Strava: recent robust je dlhodobo najsilnejší.
- Osobná starostlivosť: recent robust.
- Poistenie: last-year je výrazne lepší než modely, ktoré rozlievajú ročný náklad do viacerých mesiacov.
- Dane: seasonal-index je stabilnejší než recent/multi-year level.
- Domácnosť: multi-year trend má dobrý dlhodobý výsledok.
- Darčeky: multi-year trend / sezónny model sú veľmi blízko; preferuje sa stabilnejší multi-year prior.
- Dovolenky a Doprava: rozdiely medzi modelmi sú menšie a nestabilnejšie, preto zostáva konzervatívny adaptívny prior, kým challenger nepreukáže jasné zlepšenie.
- Úspory: príliš málo dát na agresívny výber, zostáva fallback.

## Model governance

Počiatočný prior sa môže zmeniť iba na základe nových walk-forward dát:
- pri menšej vzorke challenger potrebuje aspoň 8 % zlepšenie,
- pri 36+ validačných obdobiach aspoň 5 %.

Income Engine sa v tejto verzii nemení.
