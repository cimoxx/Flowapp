# Flow v2.51.0 – Prihlásenie cez Google

## Ako to funguje
1. Appka zobrazí tlačidlo „Prihlásiť sa cez Google“. Kým nie si prihlásený, dáta sú skryté a appka neposiela na backend žiadne požiadavky.
2. Google vráti podpísaný doklad (ID token). Backend ho overí priamo u Google (podpis, Client ID, vydavateľ, platnosť, overený e-mail).
3. Backend skontroluje hárok **FlowUsers**. Povolený účet dostane náhodný session token platný 90 dní. Do hárku **FlowSessions** sa ukladá iba jeho SHA-256 hash.
4. Session sa pri používaní automaticky predlžuje (keď zostáva menej ako 60 dní).
5. Odpoveď „Unauthorized“ (vypršané prihlásenie, vypnutý účet) vráti appku na prihlasovaciu obrazovku. Lokálne dáta ani neodoslané zmeny sa nemažú.

## Nasadenie – dodrž poradie

### Krok 1: Google Apps Script (ako prvý)
Starý zdieľaný token počas prechodu ďalej platí, takže doterajšia appka funguje aj po tomto kroku.

1. Otvor tabuľku Flow → **Rozšírenia → Apps Script**.
2. Nahraď celý obsah skriptu súborom `google-apps-script/Flowapp-Google-Apps-Script-v2.51.0.gs` a ulož (Ctrl+S).
3. Hore v zozname funkcií vyber **setupFlowAuth** a klikni **Spustiť**.
   - Google si vyžiada nové povolenie (skript bude overovať prihlásenie u Google):
     **Skontrolovať povolenia** → vyber svoj účet → „Google tento aplikáciu neoveril“ → **Rozšírené** → **Prejsť na … (nebezpečné)** → **Povoliť**.
     Je to tvoj vlastný skript, varovanie je pri súkromných skriptoch bežné.
   - V Denníku vykonávania má byť `"users":4`. V tabuľke pribudnú hárky **FlowUsers** a **FlowSessions**.
4. **Nasadiť → Spravovať nasadenia** → ceruzka pri existujúcom nasadení → Verzia: **Nová verzia** → **Nasadiť**.
   Nastavenia „Spustiť ako: Ja“ a „Kto má prístup: Ktokoľvek“ nemeň. URL ostane rovnaká.

### Krok 2: Appka
Zlúč Pull Request do `main`. Workflow nasadí appku na GitHub Pages.
Na každom zariadení otvor Flow a prihlás sa. Ak sa ešte zobrazuje stará verzia, zatvor appku a otvor ju znova.

### Krok 3: Vypnutie starého tokenu (o pár dní)
Keď sa všetci prihlásili na všetkých zariadeniach:
Apps Script → vyber funkciu **disableLegacyToken** → **Spustiť**. Nové nasadenie netreba.
Ak by sa niečo pokazilo, `enableLegacyToken` starý token znova zapne.

## Správa používateľov (hárok FlowUsers)
| Stĺpec | Význam |
|---|---|
| Email | Google účet (malými písmenami) |
| GoogleSub | Doplní sa pri prvom prihlásení, potom sa účet spoznáva podľa neho |
| Role | owner / member (zatiaľ len informačné) |
| Active | TRUE / FALSE – FALSE okamžite (do 10 minút) zablokuje aj už prihlásené zariadenia |

Nový účet: pridaj riadok s e-mailom a `Active = TRUE` a pridaj ho aj medzi **Test users** v Google Cloud (Google Auth Platform → Audience).

## Keď niečo nejde
- **„Backend ešte nemá prihlásenie“** – nie je nasadený GAS v2.51.0 (krok 1, bod 4).
- **„Účet … nemá povolený prístup do Flow“** – e-mail chýba vo FlowUsers alebo má Active = FALSE.
- **„Neplatný Google Client ID“** – Client ID v GAS a v appke sa nezhoduje.
- **Tlačidlo Google sa nezobrazí / chyba origin** – v Google Cloud → Clients → Flow web musí byť v Authorized JavaScript origins presne `https://cimoxx.github.io`.
- **„Access blocked“ od Google** – účet chýba medzi Test users v Google Cloud.
