# FLOW v2.38 – Multi-year forecast + true walk-forward backtest

## Hlavné zmeny
- rýchly index transakcií podľa mesiac/kategória; forecast už neopakuje full-scan databázy,
- forecast využíva všetky dostupné historické roky cez robustnú sezónnosť, 12-mesačný baseline a mierny trend,
- historický backtest je walk-forward: pre cieľový mesiac nepoužíva dáta z budúcnosti ani aktuálne pravidelné plány,
- pravidelné platby v backteste sú odhadované z historických skutočných recurring transakcií,
- historické vyhodnotenie sa nespúšťa automaticky pri prvom otvorení; používateľ ho spustí tlačidlom,
- prvý štart nepočíta celý ročný forecast, pokiaľ nie je otvorený Ročný plán,
- zachovaný je limit generovania pravidelných platieb max. 12 mesiacov dopredu,
- UI a sync indikátor zostávajú bez zámernej zmeny.

## Nasadenie
1. Nahraj obsah `Flowapp-main` na GitHub Pages namiesto predchádzajúcej verzie.
2. Google Apps Script zatiaľ nemeníme – táto verzia využíva existujúce API.
3. Po nasadení sprav hard refresh / vyčistenie cache Service Worker.
