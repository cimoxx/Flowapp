# Flow v2.43.5 – Category Data Protection

Táto verzia rieši stratu vlastných kategórií po vymazaní cache/cookies.

## Ochranné vrstvy
1. Generický starter set sa už nepoužíva ako live fallback a klient ho nikdy neodošle do cloudu.
2. Po strate lokálneho stavu sa pred akýmkoľvek category push najprv načíta cloudový baseline.
3. Posledný potvrdený master kategórií je zabudovaný ako read-only recovery fallback.
4. Kategórie bez uid dostávajú stabilné deterministické uid podľa názvu.
5. GAS v2.43.5 poskytuje `categories_meta` s Version/UpdatedAt a blokuje generický starter set aj na serveri.
6. Pred každou zmenou cloudových kategórií GAS uloží predchádzajúci stav do `CategoriesBackup`; drží posledných 100 snapshotov.
7. Pri zistení presného starého generického setu aplikácia použije recovery master a bezpečne opraví cloud.

## Nutný krok
Pre plnú serverovú ochranu treba nasadiť `Flowapp-Google-Apps-Script-v2.43.5.gs` ako novú verziu existujúceho Web App deploymentu. URL môže zostať rovnaká.

Budget, forecast model a Income Engine neboli menené.
